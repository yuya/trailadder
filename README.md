# trailadder

公開前後1か月の映画の予告編を、公開日順にスワイプで観ていくプレイヤーです。
縦向きにロックしたままでも、画面は横いっぱいに使います。

## 使い方

1. ページを開き、[TMDB の API キー](https://www.themoviedb.org/settings/api)を入れます（32桁のキーでも、`eyJ` で始まるトークンでも可）。キーはそのブラウザの中にだけ保存されます。
2. 今日に一番近い公開作から始まります。

| 操作 | 動き |
| --- | --- |
| 左右にスワイプ | 次の作品／前の作品（公開日順） |
| タップ | 操作パネルの表示／非表示 |
| 左右の端をダブルタップ | 10秒戻る／進む |
| 上にスワイプ | 作品の詳細とほかの映像 |
| ピンチ | 映像を画面いっぱいに拡大／元に戻す |
| 下段のカレンダーをなぞる | その公開日へ移動（点灯＝公開済み、今日で灯りが止まる） |

パソコンでは ← → で作品送り、スペースで再生／一時停止、M で音、F で拡大、I で詳細です。

## 置き場所

ビルドは不要で、`index.html` を https で配信すれば動きます（GitHub Pages なら Settings → Pages → Deploy from a branch → `main` / root）。
YouTube は https のページでしか埋め込み再生を許可しないため、ファイルを直接開いても再生されません。
スマートフォンでは「ホーム画面に追加」するとブラウザの枠なしで開けます。

## データ

作品情報と画像は TMDB から取得しています。This product uses the TMDB API but is not endorsed or certified by TMDB.
映像は YouTube の埋め込みプレイヤーで再生しています。
