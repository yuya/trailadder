# trailadder

公開から1か月以内の映画と、2か月先までの公開予定作の予告編を、公開日順にスワイプで観ていくプレイヤーです。
縦画面が基本で、右上のボタンで横画面に切り替えられます。横画面は本体の画面の回転ロックをオンにしたまま、横いっぱいに使います。

## 使い方

開くとすぐ、今日に一番近い公開作から始まります。最後まで進むと最初に戻り、最初から戻ると最後に移ります。

| 操作 | 動き |
| --- | --- |
| 左右にスワイプ | 次の作品／前の作品（公開日順） |
| 映像の中央をタップ | 再生／一時停止 |
| 映像の左右をタップ | 操作パネルの表示／非表示（横画面） |
| 映像の下をタップ | 作品の詳細（縦画面） |
| 左右の端をダブルタップ | 10秒戻る／進む |
| あらすじを上になぞる（縦画面） | 詳細がその場で続く（左右スワイプで作品送り、一番上で下に引くと閉じる） |
| 右下の「詳細」（横画面） | 動画を左に寄せ、右に作品の詳細を並べる（もう一度押すと閉じる） |
| 共有ボタン | この予告編へのリンクを共有（共有できない環境ではコピー） |
| ピンチ | 映像を画面いっぱいに拡大／元に戻す（横画面） |
| 下段のカレンダーをなぞる | その公開日へ移動（点灯＝公開済み、今日で灯りが止まる） |

パソコンでは ← → で作品送り、スペースで再生／一時停止、M で音、F で拡大、I で詳細、O で縦横の切り替え（スマートフォン）です。

## 構成

- `index.html` … サイト本体（CSS・JS も中に入っている1ファイル。ビルドなし）
- `data/archive.json` … これまで掲載したすべての作品の題名・公開日・映像。共有リンク（`?f=<TMDB の作品ID>`、別の映像なら `&v=<YouTube の動画ID>`）を、掲載期間が過ぎた後も開けるようにするため。自動で作るので手で編集しない
- `data/films.json` … 作品と予告編の一覧。**自動で作るファイルなので手で編集しない**。日本の公開日が「今日の1か月前〜2か月後」の作品のうち、YouTube の予告編がある作品だけが入る
- `scripts/fetch-films.mjs` … TMDB から上のファイルを作るスクリプト
- `.github/workflows/films.yml` … 毎朝 6:13（日本時間）にスクリプトを実行し、変わっていれば `main` にコミットする。Actions の画面から手動でも実行できる（Update films → Run workflow）
- `manifest.webmanifest`・`icons/` … ホーム画面に追加したときの名前とアイコン

ページは `data/films.json` を1回読むだけで、閲覧時に TMDB へはアクセスしない。表示する期間は開いた日に合わせてページ側で絞り込む。

## TMDB

リポジトリの Secret `TMDB_TOKEN`（Settings → Secrets and variables → Actions）に TMDB の「API 読み取りアクセストークン」を入れておくと、Actions がそれを使ってデータを作る。トークンはブラウザにも公開先にも置かない。

## 公開（Cloudflare Pages）

1. Cloudflare のダッシュボードで Workers & Pages → 作成 → Pages → Git に接続 → このリポジトリを選ぶ
2. 本番ブランチ `main`、フレームワーク「なし」、ビルドコマンドは空、出力ディレクトリ `/`
3. 公開後、カスタムドメインを追加する

`main` に push されるたびに（毎朝のデータ更新も含めて）自動で公開し直される。

YouTube は https のページでしか埋め込み再生を許可しないため、ファイルを直接開いても再生されない。
スマートフォンでは「ホーム画面に追加」するとブラウザの枠なしで開ける。

## データ

作品情報と画像は TMDB から取得しています。This product uses the TMDB API but is not endorsed or certified by TMDB.
映像は YouTube の埋め込みプレイヤーで再生しています。
